Project overview

This project converts cleaned BITRE speeding enforcement data into an interactive D3.js dashboard for exploration and teaching. The site provides per-jurisdiction, detection-method and demographic breakdowns of fines across Australia.

Course: COS30045 Data Visualisation, Swinburne University of Technology

Stack: D3.js, HTML/CSS, KNIME  •  Language: JavaScript
